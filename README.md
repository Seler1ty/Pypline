# DataBase Pypline

Перенос данных в базу данных

## Функционал

1. **Запросы к базе данных** - получение/дополнение/изменение/удаление данных
2. **Анализ доступности** - определение доступности парков из каждого квартала по пешеходным маршрутам
3. **Автоматизаированный процесс обработки данных** - сохраняется прогресс обработки, можно начать после прерывания


## Описание файлов:

### db.py
> Подключение к базе данных. Данные беруться из credentials.py

### coords_fill.py
> 1) get_cities() - возвращяет список city_id
> 2) get_quarters(city_id) - возвращает список из id, координат центра, X, Y квартала
> 3) get_green_zones(city_id) - возвращает список из id, координат центра, X, Y зоны
> 4) save_route_ends(q_id, gz_id, q_center, gz_center) - заводит запись в таблице distance, заполняя поля с id квартала и зоны, а также с центрами квартала и зоны
> 5) mark_quarter_done(q_id) - ?
> 6) process() - связующая функция, перебирает города, кварталы и зоны, проверяет прямые расстояния и решает, делать ли запись 

### process_routes.py

> 1) get_unprocessed_distances(start_id, end_id, limit=100) - возвращает список необработанных маршрутов (именно по кривой) с полями id, x и y квартала, x и y зоны
> 2) update_route(distance_id, curve_distance) - заносит расстояние по кривому маршруту в поле с соответствующим id маршрута
> 3) process_routes(start_id, end_id) - обрабатывает записи таблицы distances в определённом диапазоне
