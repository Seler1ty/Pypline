# DataBase Pypline

Перенос данных в базу данных

## Функционал

1. **Запросы к базе данных** - получение/дополнение/изменение/удаление данных
2. **Анализ доступности** - определение доступности парков из каждого квартала по пешеходным маршрутам
3. **Автоматизаированный процесс обработки данных** - сохраняется прогресс обработки, можно начать после прерывания
